# A better way to track what you read

Welcome to **Blog Ledger**, a study project for the University of Helsinki's **Full Stack Open: Next.js** course.

## Explore ideas

Browse posts, search by title, and open an individual post to see its author and likes.

## Create your own space

Register a local account to publish posts and build your personal reading list. Add other people's posts, mark them as read, and explore how Server Actions keep UI and database data in sync.

This example demonstrates React Server Components, file-based routing, Tailwind CSS, NextAuth, Drizzle ORM, PostgreSQL, API tokens, and automated browser tests.
