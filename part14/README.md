# Part 14 — Next.js (2026)

The Blog List project in the bloglist folder implements the Next.js section using server components, server actions, Drizzle/Postgres, credentials authentication, reading lists, API tokens, validation, Tailwind, and MDX.

The code is for practice only. The Neon database, Vercel deployment, and GitHub Actions secrets need configuring before the full hosted tests can run. See the project README for setup and remaining external steps.
