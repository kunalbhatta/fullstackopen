# Phonebook — Full Stack Open Part 2 (exercises 2.6–2.17)

Run in **two terminals** from this directory:

```bash
npm install
npm run server
```

```bash
npm run dev
```

Open the Vite URL (normally http://localhost:5173/). The `json-server` REST API runs at http://localhost:3001/persons.

Test: load entries; filter case-insensitively; create a person; update a duplicate name after confirmation; delete after confirmation; inspect green and red notifications. In two tabs, modify a now-deleted entry to test the 404 notification.
