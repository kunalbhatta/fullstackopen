# Full Stack Open — Part 2 (exercises 2.1–2.20)

Final-state projects:

- `courseinfo/`: exercises 2.1–2.5, including reduce and a separate Course module.
- `phonebook/`: exercises 2.6–2.17, including JSON Server CRUD, extracted Axios module and notifications.
- `countries/`: exercises 2.18–2.20, using the course's country API and no-key Open-Meteo weather data.

Run `npm install` then `npm run dev` in each project. The phonebook additionally needs `npm run server` in another terminal.

**Review and test** the exercises yourself before marking them complete in the course submission system. Do not submit Part 2 until you finish all the exercises you want credited.
